# AgriOS Website — deploy folder

This folder contains the complete AgriOS website, ready to go live.

## Quickest way to get live

1. Open a Claude Code session in this folder.
2. Tell it: **"Read CLAUDE.md and get this website live on Vercel."**
3. Follow its steps. You'll have a live URL in under an hour.

## What's here

- `index.html` — the website (all 5 pages)
- `admin.html` — the admin panel demo
- `logo-wordmark.png`, `logo-full-web.png`, `favicon.png` — the logos
- `CLAUDE.md` — instructions for Claude Code (what to do, what not to touch)
- `vercel.json` — deploy config

## To preview right now (no Claude Code needed)

Just double-click `index.html` — it opens in your browser with the logo and everything.
(The images must stay in the same folder as the HTML.)
